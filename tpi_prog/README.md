Trabajo Práctico Integrador (TPI)
Gestión de Datos de Países en Python: filtros, ordenamientos y
estadísticas

El programa realizado tiene la funcionalidad de leer, actualizar, ordenar un diccionario de países predefinidos, con la posibilidad de agregar nuevos a la lista

Tecnologías Utilizadas:
Lenguaje: Python 3.x
Librerías: questionary (para la selección de opciones predefinidas), csv (nativa).
Editor: Visual Studio Code.

Requisitos e Instalación
1-Clonar el repositorio o descargar los archivos.
2-Instalar la librería questionary abriendo una terminal y ejecutando: pip install questionary

Instrucción de uso: 
1-Abrir una terminal en la carpeta del proyecto.
2-Ejecutar el archivo principal: python tpi_prog.py
3-Navegar por el menú con las flechas del teclado y seleccionar con Enter.

Funcionalidades del Sistema:

-Agregar País: Permite sumar un país nuevo validando que no queden campos vacíos.

-Actualizar Datos: Modifica la población y superficie de un país existente.

-Búsqueda: Encuentra países por nombre (coincidencia exacta).

-Filtros: Filtra por continente o por rangos (mínimo/máximo) de población y superficie.

-Ordenamiento: Ordena la lista por nombre, población o superficie en forma ascendente o descendente.

-Estadísticas: Calcula mayor/menor población, promedios y cantidad de países por continente.
